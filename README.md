# RustArch v0.7.0

**RustArch** — быстрый, легковесный и полностью автономный графический архиватор для Windows, написанный на Rust с использованием GUI-фреймворка `egui` (`eframe`).

Приложение скомпилировано в один компактный исполняемый `.exe`-файл со статической компоновкой CRT (`+crt-static`) и не требует наличия сторонних DLL или установленных сред выполнения.

---

## Основные возможности

### 🚀 Высокая производительность и управление ресурсами
- **Ускорители памяти и сжатия**: Использование высокопроизводительного аллокатора памяти `mimalloc` и быстрой реализации `zlib-rs`.
- **Многопоточность и контроль нагрузки**: Параллельное сжатие с возможностью ограничения потоков CPU (автоопределение количества ядер или ручной выбор с помощью ползунка).
- **Информативный прогресс**: Двухстрочный индикатор прогресса с точным расчётом оставшегося времени (ETA), системный звуковой сигнал и подсветка (мигание) окна на панели задач по завершении операции.
- **Полная автономность**: Единый независимый бинарный `.exe` без внешних зависимостей.

### 🔐 Запароленные архивы и интерфейс (v0.7.0)
- **Распаковка и проверка целостности защищённых архивов**:
  - Поддержка зашифрованных архивов `.zip` (ZipCrypto + WinZip AES-128/256) и `.7z` (AES-256, включая шифрование имён файлов), а также многотомников `.001/.002...`.
  - Автоматическое определение защиты паролем при открытии или перетаскивании архива, окно ввода пароля с переключателем видимости текста.
  - Безопасный повторный ввод пароля при опечатке без создания пустых или битых папок на диске — работает как при распаковке, так и при проверке целостности.
- **Улучшения интерфейса (UI)**:
  - Устранена тряска модальных окон в `egui` при разных разрешениях и масштабах экрана.
  - Выровнена сетка кнопок в один ряд во всех диалогах.

### 🛡️ Надёжность и безопасность данных
- **Проверка целостности архивов**:
  - Автоматическая проверка целостности сразу после сжатия (включается в Настройках) с подробным окном отчёта.
  - Ручная кнопка «Проверить» для любых скачанных архивов и многотомников `.001/.002...` — тестирование контрольных сумм и структуры происходит в оперативной памяти без лишней записи на диск.
- **Автоудаление исходных файлов после распаковки**:
  - Опция в Настройках с обязательным окном подтверждения риска.
  - Удаляет исходный архив или все составные части многотомника `.001/.002...` строго при 100% успешном завершении распаковки без ошибок и отмены пользователем.

### 📦 Поддерживаемые форматы
- **Сжатие и распаковка**:
  - `.zip` — многопоточное создание архивов с автоматической поддержкой ZIP64 для работы с файлами и архивами размером более 4 ГБ.
  - `.7z` — многопоточное сжатие LZMA2.
  - `.tar.zst` — современное сверхбыстрое сжатие Zstandard (`zstdmt`).
  - `.tar.xz` — максимальная степень сжатия LZMA2/XZ.
  - `.tar.br` — алгоритм Brotli.
  - `.tar.gz` — классический Gzip на базе оптимизированного `zlib-rs`.
  - `.tar.lz4` — ультра-быстрое сжатие LZ4.
- **Распаковка**:
  - Поддержка распаковки всех вышеперечисленных форматов, а также архивов `.tar.bz2` (Bzip2).

### 🧩 Многотомные архивы (Split Archive)
- Поддержка разбиения архивов на тома фиксированного размера:
  - **19 МБ** (оптимально для загрузки в Discord)
  - **50 МБ**
  - **100 МБ**
  - **Пользовательский размер** (в мегабайтах)
- Потоковая сборка и распаковка частей `.001/.002...` напрямую без промежуточных файлов на диске.

### 💻 Интеграция с Windows и интерфейс
- **Ассоциации файлов**: Возможность прямого открытия по двойному клику файлов `.001`, `.xz`, `.zst`, `.br`, `.lz4` (а также опционально `.7z`).
- **Контекстное меню Windows (ПКМ)**: Интеграция пункта «Открыть в RustArch» для файлов и директорий через ветку реестра `HKCU` без требования прав администратора (UAC).
- **Автопроверка обновлений**: Встроенная проверка свежих версий через GitHub Releases (установленная версия сама скачивает и запускает свежий `Setup.exe`, а Portable-версия открывает страницу релиза).
- **Темы оформления**: Поддержка тёмной и светлой темы интерфейса.
- **Готовый инсталлятор и скрипт сборки**: Инсталлятор Inno Setup с чистым удалением, а также удобный скрипт `build_release.bat` для автоматической сборки Portable-версии и установщика в один клик.

## Скачивание и установка

Свежие сборки доступны на странице [Releases](https://github.com/qpwqp069-sys/RustArch/releases):
- **`RustArch_Setup_v0.7.0.exe`** — полноценный установщик (выбор папки, ярлык на рабочем столе, интеграция в контекстное меню ПКМ, ассоциации файлов, автообновление и удаление через Windows).
- **`RustArch_Portable_v0.7.0.exe`** — портативная версия (один автономный `.exe`, работает сразу без установки).

## Сборка из исходников

Для самостоятельной сборки потребуется установленный компилятор [Rust](https://rustup.rs/) (инструментарий `stable-x86_64-pc-windows-msvc`).

### Ручная сборка
```bash
cargo build --release
```
Скомпилированный бинарный файл будет находиться в каталоге:
```
target/release/rust_archiver.exe
```

### Автоматическая сборка релиза
Для одновременной сборки оптимизированного бинарного файла, подготовки Portable-версии и компиляции Inno Setup инсталлятора запустите:
```cmd
build_release.bat
```
Все готовые артефакты будут помещены в папку `dist/`.
